# NodeStar

NodeStar is an AI product studio and implementation partner. We build AI systems for real business workflows, and each install is a fixed-scope project that puts an AI system on one named job: answering the phone, recovering lost leads, getting your business named by AI search engines, or running a shopping agent on your online store. Setup is quoted at a fixed price after a short call, and every install is tuned after launch.
